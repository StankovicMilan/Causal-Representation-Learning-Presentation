# Causal Representation Learning Presentation

Beamer slides on Zhang et al. (2023), *Identifiability Guarantees for Causal Disentanglement from Soft Interventions*,
for the ETH Student Seminar in Statistics: Representation Learning (30.11.2026).

Build with `make` (needs a TeX Live with beamer, TikZ and latexmk). `make notes` builds a version with speaker notes.
See `CLAUDE.md` for the file layout, notation macros and style rules.
